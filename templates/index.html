🧠 How the NLP Works

Two production-ready models, plus a powerful deep learning model on the roadmap.

🧪 VADER

Rule-based sentiment analyzer specifically tuned for social media. Handles emojis, slang, and emphasis (ALL CAPS, punctuation!!!).

~87% Accuracy

📊 TextBlob

Pattern-based analysis using a pre-trained dictionary. Returns both polarity (sentiment) and subjectivity scores.

~82% Accuracy

🤖 BERT (RoBERTa)

Deep learning model fine-tuned on Twitter data. Captures context and nuance that rule-based models miss. Requires significant compute resources.
